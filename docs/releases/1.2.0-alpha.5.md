# 1.2.0-alpha.5 — Portable Linux library lookup

- Both `mnx` and `mnxi` now include a Linux `$ORIGIN` library search path.
  Keep the separately built `libmnxfile.so.1` beside the executables for a portable
  installation, including `~/.local/bin/`. System package installations still work.
- The MNX engine remains an independently replaceable shared library. No archive
  format, command syntax or Windows behavior changed.
- Verified native linking and the existing CLI, list, search, interactive terminal,
  cancellation and version checks. A direct installed-location check confirmed
  loading the adjacent engine without a system library entry or environment override.
